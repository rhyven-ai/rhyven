# Reusable text code

textkit.py contains ordinary Python functions: normalization and slug bricks,
a field-renaming mortar function, and a composed document-preparation stack.
None imports Rhyven or uses its storage.

Validate/test before saving. Export once and import the functions directly.
See docs/portable-pallets.md and the document-intake app example for commands.
Public sharing is not part of this example.
