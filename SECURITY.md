# Reporting security issues

Report suspected vulnerabilities privately through
[Rhyven's security advisory form](https://github.com/rhyven-ai/rhyven/security/advisories/new).
Do not post credentials, customer data or exploit details in public issues.

Include the version, operating system, app ID/version and image digest when
relevant, the affected operation and steps using synthetic data. The current
release is a preview; no response-time SLA or certification is claimed.

The engine, adapters, installer, website and Rhyven apps are in scope. Test only
instances you own or are authorized to assess. Do not test other customers or
third-party infrastructure. Remove secrets and host-specific data from reports.

Private reporting is also available through the
[registry advisory form](https://github.com/rhyven-ai/registry/security/advisories/new).
See the [publication runbook](docs/publication.md) for release checks.
