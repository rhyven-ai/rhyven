# Website assets

## Rhyven brand

`rhyven-brand.png` is the original Rhyven brand image supplied by the project
owner. CSS displays its beacon icon without the old tagline or palette swatches.
`favicon.svg` is a geometric beacon drawn for the browser tab.

## Corvid background

`corvid-crows-pixel.png` was generated with OpenAI image generation on 2026-09-26,
using `corvid-ravens.png` as an edit reference. It depicts a stylized pixel-art
murder of crows in a dark blue landscape. CSS preserves crisp pixels when scaling.

## Fonts and icons

Lato Regular and Bold use OFL-1.1; retain `fonts/LICENSE.txt`. Interface icons are
inline SVG paths. Construction tape and the coming-soon emblem use CSS and SVG.
